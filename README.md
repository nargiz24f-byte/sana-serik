# САНА-СЕРІК — толық жоба

«САНА-СЕРІК» — оқушыға эссені өз бетімен жазуға көмектесетін, бірақ оның орнына дайын мәтін жазбайтын ЖИ-ойлау серігі.

## Мүмкіндіктер

- Оқушының аты-жөні, сыныбы және эссе тақырыбы;
- эссе жазу аймағы және сөз саны;
- Gemini AI-мен қазақ тілінде чат;
- дайын эссе сұрағанда академиялық адалдыққа сай бас тарту;
- эссені 5 критерий бойынша 10 баллдық жүйемен бағалау;
- күшті жақтар мен жақсарту бағыттары;
- академиялық адалдықты растау;
- оқушы жұмысын серверде сақтау;
- мұғалім панелі: барлық жұмыстарды көру және өшіру;
- нәтижелерді CSV ретінде жүктеу.

## Іске қосу

1. Node.js 18+ орнатыңыз.
2. Терминалда жоба бумасына кіріңіз.
3. Тәуелділіктерді орнатыңыз:

```bash
npm install
```

4. `.env.example` файлын `.env` деп көшіріңіз.
5. `.env` ішінде:
   - `GEMINI_API_KEY` — өз Gemini API кілтіңіз;
   - `TEACHER_PASSWORD` — мұғалім панеліне арналған жаңа құпиясөз.
6. Іске қосыңыз:

```bash
npm start
```

7. Браузерде ашыңыз:

```text
http://localhost:3000
```

## Қауіпсіздік

- API кілтін оқушыларға бермеңіз.
- API кілтін `public/index.html` ішіне жазбаңыз.
- `.env` файлын GitHub-қа жүктемеңіз.
- Жария серверде міндетті түрде `TEACHER_PASSWORD` мәнін ауыстырыңыз.

## Деректер

Оқушы жұмыстары `data/submissions.json` файлына сақталады. Бұл шағын мектептік прототипке ыңғайлы. Көп қолданушыға арналған нұсқада Firebase/PostgreSQL сияқты дерекқорға көшіруге болады.
